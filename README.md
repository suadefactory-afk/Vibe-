# Vibe Social App

Vibe is a beginner-friendly front-end prototype for a community-focused social app.

## Run it
1. Download or clone this repository.
2. Keep the folder structure shown below.
3. Open `index.html` in a browser.

No build tools are required.

## Features in this prototype
- Responsive home feed
- Create posts
- Like and unlike posts
- Search posts
- Light and dark theme
- Vibe World preview
- Saves posts in the current browser using local storage

## Publish with GitHub Pages
1. Create a GitHub repository named `vibe-social-app`.
2. Upload the contents of this folder. Make sure `index.html` is in the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for GitHub Pages to publish your site.

## Important prototype note
This is a front-end demonstration, not a complete social network. Posts are stored only in the browser that created them. Real accounts, secure sign-in, shared posts, messaging, moderation and a server database need a trusted backend before public launch.
