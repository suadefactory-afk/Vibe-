# Vibe development notes

## Current stage
This project is a static front-end prototype. It is suitable for learning HTML, CSS, JavaScript and GitHub Pages.

## Suggested build order
1. Polish the feed and responsive layout.
2. Add profile pages using sample data.
3. Design a safe sign-up flow as a non-functional mock-up.
4. Choose a backend and database with adult/teacher guidance.
5. Add authentication, permissions and data validation securely.
6. Build reporting, blocking and moderation tools before inviting real users.
7. Test accessibility, mobile layouts and performance.

## Current limitations
- There is no server or shared database.
- There is no real account system.
- Posts are saved in local browser storage and are not shared with other people.
- The Vibe World and community links are previews/placeholders.
- The share control copies post text where browser permissions allow.

## Working with GitHub
Keep `index.html`, `style.css` and `script.js` together in the repository root. Keep the SVG in `assets/icons/` and the two documentation files in `docs/`.
